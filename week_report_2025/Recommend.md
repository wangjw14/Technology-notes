# Recommend

## 前深度学习阶段

### 协同过滤

- userCF流程
  - 先建立user-item相似度矩阵
  - 然后计算用户相似度（可以使用cos相似度、皮尔逊相关系数等）
  - 根据用户相似度，找到相似的用户，然后该用户对item的偏好等于相似用户的加权相似度
- userCF的缺点
  - 当用户数量增大之后，开销太大（用户数远大于物品数）
  - 相似矩阵很稀疏（尤其是大件商品购买等低频应用）
- itemCF流程
  - 先建立user-item相似度矩阵
  - 计算物品相似度
  - 获取用户的历史行为中的正反馈item
  - 针对每个item找到topK的物品
  - 加权计算得到每个item的最终相似度
- userCF vs itemCF
  - userCF具有更强的社交属性，适用于新闻推荐场景
  - itemCF适用于兴趣变化较为稳定的应用，如电商等
- CF的缺点
  - 推荐结果头部效应明显，处理稀疏向量能力差
  - 无法有效引入用户的年龄、性别的属性信息

### 矩阵分解（Matrix factorization）

- 算法思想：将user-item共现矩阵进行分解，得到 item 向量和 user 向量
- 矩阵分解的求解方法：
  - 特征值分解：只适用于方阵
  - 奇异值分解：适用于稠密矩阵，且计算复杂度高
  - 梯度下降法：适用于推荐系统
- 矩阵分解的优化
  - 增加参数正则项，防止过拟合
  - 消除user和item打分的偏差
- 矩阵分解的优点
  - 泛化能力强，一定程度上解决了协同过滤的稀疏性问题
  - 空间复杂度低，(m+n)k
  - 更好的扩展性，可以和深度学习模型进行无缝结合
- 矩阵分解的缺点
  - 同样无法加入用户和上下文信息

### 逻辑回归

- 思路：综合利用user、item、上下文等多种特征，将推荐转换为一个CTR（是否点击的分类）问题
- 流程：
  - 将user、item的各种特征转换为数值型特征向量
  - 以优化点击率为目标，进行模型训练，确认模型参数
  - 在线推理，得到 user 点击 item 的概率
  - 根据概率进行排序，得到推荐列表
- 求解方法：梯度下降
- 优势：
  - 数字含义上支撑：因变量服从伯努利分布
  - 可解释性强：输出是概率，且可以通过权重解释特征的重要程度
  - 工程化容易：易于并行化、训练开销小
- 缺点：
  - 表达能力不强，无法进行特征交叉、需要特征选择等

### 特征交叉方案

- 为什么需要特征交叉：避免辛普森悖论（单一特征有时不仅是信息损失，甚至可能得出错误结论）
- POLY2
  - 将所有特征都两两交叉，权重参数数量直接从 $n$ 上升为 $n^2$ 级别
  - 优点：便于和逻辑回归进行兼容
  - 缺点：数据更加稀疏、参数量上升巨大，极大增加了训练复杂度
- FM（Factorization Machines）
  - 思路：每个特征使用一个权重向量，用一个向量的内积取代了POLY2中单一的权重
  - 将权重的复杂度从 $n^2$ 下降到 $nk$ ，训练复杂度得到了同样程度的下降
  - 隐向量的引入，能够更好的解决稀疏性问题
  - 使用梯度下降方法进行优化

- FFM
  - 思路：在FM的基础上，再继续引入域的概念。同一个特征，对于不同的域，有不同的隐向量
  - 参数量：$nkf$，训练量：$kn^2$
  - 引入了更多有价值的信息，但是计算复杂度上升很多，需要在效果和投入之间权衡

### GBDT+LR

- 思路：FM只能做二阶特征交叉，如果继续提升特征交叉维度，会产生组合爆炸和计算复杂度。因此产生了基于GBDT+LR的组合。GBDT进行特征的选择和组合，然后再通过LR进行CTR预估。
- GBDT的特征转换
  - 首先训练一个GBDT，后面一棵树以前面树的结果和真实结果的残差为拟合目标。树中每个节点的分裂都是一个自然的**特征选择**的过程。多层节点的结构则对特征进行了有效的**自动组合**。
  - 样本进入GBDT的某一子树之后，最终会根据规则落入某个叶子节点，该叶子节点置为1，其他的置为0。所有子树的向量拼接得到最终的特征向量。
  - 决策树的深度决定了特征交叉的阶数。如果树深度为4，则通过了3次节点分裂，是三节特征组合。
- GBDT+LR组合意味着特征工程可以由一个独立的模型完成，避免了过多的人力投入，并实现端到端训练。

### LS-PLM

- 又被称为MLR（Mixed Logistic Regression）
- 思路：不同的用户群体之间，分别进行建模，避免不同用户的特征相互干扰
- 流程：
  - 先对用户进行分类。分类树可以平衡模型的拟合和泛化能力，经验值为12。
  - 然后用LR模型计算样本在分片中具体的CTR，然后将二者相乘后求和
- 另一种理解：通过聚类，相当于引入了一个新的神经网络层，并且是一个attention层
- 优点：
  - 端到端的非线性学习能力
  - 模型的稀疏性强，可以提升在线推理效率

## 深度学习阶段

### AutoRec

- 思路：通过一个 AutoEncoder 将user-item矩阵进行编码（先压缩再复原）
- 可以分为 Item based AutoRec 和 User based AutoRec
- 模型结构：输入层，隐层，输出层，一共三层
- 特点：有一定的泛化和表达能力，但是模型结构简单，表达能力不足。

### Deep Crossing

- 网络结构：embedding层、stacking层、Multiple-Res层，输出层
- 离散型输入直接进embedding，数值型直接进模型，stacking层将不同的embedding、数值型输入拼接，通过多层res层，进行特征的自动交叉组合，然后最后进行输出层进行loss计算
- 影响：历史性的提出了“embedding+多层神经网络”的经典深度学习结构。没有任何人工特征的参与，全部特征交叉任务都是通过神经网络进行“深度交叉”

### FM与深度学习结合

- FNN
  - 网络结构和 DeepCrossing 类似，但是使用了 FM 的参数进行初始化，从而加速模型的收敛

- DeepFM
  - 使用 FM 替换 Wide&Deep 的 wide 部分，加强特征的组合能力
- NFM
  - FM无法建模三阶以上的特征，因此使用一个建模能力更强的函数替代二阶部分。该替代网络中加入了特征交叉池化层。
