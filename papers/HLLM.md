# HLLM

- 三个关键问题仍未得到充分探讨
  - 首先，大语言模型预训练权重的真正价值，通常被认为包含了世界知识；
  - 其次，对于推荐任务进行微调的必要性；
  - 最后，大语言模型在推荐系统中是否能像在其他领域一样展现出相同的可扩展性优势。

- 我们的方法采用了两层模型：
  - 第一层的物品大语言模型从物品的详细文本描述中提取丰富的内容特征；
  - 第二层的用户大语言模型利用这些特征，根据用户的交互历史来预测用户未来的兴趣。
- 效果
  - 在两个大规模数据集（PixelRec 和 Amazon Reviews）上的评估显示，HLLM 取得了最先进的结果，大幅超越了传统的基于 ID 的模型。
  - 在在线 A/B 测试中，HLLM 展现出了显著的优势，验证了其在实际推荐场景中的实际影响。

- 代码：https://github.com/bytedance/HLLM



- LLM结合推荐的方法可以大致分为三种：
  - 利用大型语言模型为推荐系统提供精炼或补充信息，例如用户行为总结和物品信息扩展。
  - 将推荐系统转换为与大型语言模型兼容的对话驱动格式。
  - 修改大型语言模型以处理不仅仅是文本输入和输出的推荐任务。这包括将 ID 特征输入到大型语言模型中的方法，以及那些用大型语言模型替换现有模型、直接针对点击率（CTR）等目标进行优化的方法。
